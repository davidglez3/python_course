## Comandos Útiles de Git

Guía rápida para el flujo diario de trabajo en la terminal:

```bash
# Ver el estado actual de los archivos
git status

# Añadir los cambios realizados
git add .

# Guardar los cambios con un mensaje descriptivo
git commit -m "feat: completados los ejercicios de [tema]"

# Subir los cambios a GitHub
git push origin main

```
